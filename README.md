# RuoYi React Admin

A React-based admin panel inspired by RuoYi framework.

## Features

- Login page
- Dashboard with sidebar menu
- Ant Design UI
- React Router
- Zustand for state management
- Axios for API calls

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

- `src/api/` - API calls
- `src/components/` - Reusable components
- `src/pages/` - Page components
- `src/store/` - State management with Zustand
